# Tetrix – Aplicación Web con Angular

## Descripción
Implementación de un juego inspirado en **Tetris** desarrollado con Angular como proyecto académico.
El proyecto tiene como objetivo aplicar conceptos de programación, manejo de lógica de juego, interacción con el usuario y organización de componentes dentro de un framework moderno.

## Tecnologías
- Frontend: Angular, TypeScript
- Estilos: CSS
- Framework: Angular
- Herramientas: Node.js, npm

## Funcionalidades
- Juego basado en la mecánica clásica de Tetris
- Control de piezas mediante interacción del usuario
- Movimiento y rotación de bloques
- Sistema de puntuación
- Gestión de estados del juego
- Interfaz dinámica desarrollada con Angular
- Actualización de elementos en tiempo real

## Aprendizajes
- Desarrollo de aplicaciones con Angular
- Creación y organización de componentes
- Manejo de lógica de programación aplicada a videojuegos
- Gestión de eventos e interacción del usuario
- Uso de TypeScript para proyectos frontend
- Aplicación de estructuras y conceptos de programación orientada a objetos

## Nota

Aunque se trata de un proyecto educativo, representa una etapa importante en mi aprendizaje, donde puse en práctica conceptos de programación, desarrollo frontend y creación de aplicaciones interactivas utilizando Angular.
